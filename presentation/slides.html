The Problem

Traditional Security Fails

  • Signature-based rules miss novel attacks
  • Fixed thresholds ignore behavioral context
  • No understanding of "normal" per entity
  • Alerts lack explanations for analysts
  • New users/devices have no baseline

Our Challenge

Build an AI/ML system that:

  • Models per-entity normal behavior
  • Detects intrusions in near real-time
  • Classifies 7 attack types
  • Provides explainable risk scores
  • Handles cold-start & concept drift

ML Approach

Baseline Profiler

  • Isolation Forest (unsupervised)
  • One-Class SVM
  • Ensemble scoring
  • Population baselines for cold-start

Detection Model

  • XGBoost binary classifier
  • LSTM Autoencoder
  • Weighted ensemble (60/40)
  • scale_pos_weight for imbalance

Attack Classifier

  • Multi-class XGBoost
  • SMOTE oversampling
  • 7 attack categories
  • Confidence scores per class

Key Innovation: Risk Score = 0.6 × XGBoost_prob + 0.4 × LSTM_error → [0–100]
